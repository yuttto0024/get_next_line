## Overview

この課題は、ファイルディスクリプタから1行ずつテキストを読み込んで返す関数 `get_next_line` を作成するプロジェクトである。
関数を繰り返し呼び出すことで、ファイルの終端（EOF）に達するまでテキストファイルを1行ごとに取得できる設計となっている。

## Language & Tools

* **Language**: C
* **Build**: `cc` (コンパイル時に `-D BUFFER_SIZE=n` フラグによりバッファサイズを指定)
* **Functions**: `read`, `malloc`, `free`

## What I Learned

このプロジェクトを通じ、低レイヤのプログラミングおよびシステム開発の基礎となる以下のスキルを習得した。

* **静的変数（Static Variables）の活用**:  
Cプログラミングにおける静的変数を利用し、複数回の関数呼び出し間で読み込み状態を保持する機能を実装した。
* **ファイルI/Oと動的バッファ管理**:  
システムコール `read` を用い、任意の `BUFFER_SIZE` で指定されたバイト数ごとにデータを読み込む処理を実装した。
取得した文字列から改行文字までを抽出し、残りのデータを次回の呼び出しに引き継ぐアルゴリズムを構築した。
* **厳格なメモリ管理**:  
メモリの動的割り当て（`malloc`）と解放（`free`）を適切に行い、文字列の結合や再割り当て時にメモリリークや無効なポインタ参照が発生しない堅牢なコード設計を習得した。
* **コーディング規約の厳守**:
42のコーディング規約（Norm）を遵守し、可読性が高く、保守性の高いコードを書く訓練を行った。
